国产系统（麒麟 / 统信 UOS / deepin）安装说明

装不上的 90% 是下面两种情况，按对应步骤处理即可。

情况一：提示「安装包没有有效的数字签名，已被禁止安装」

这不是安装包损坏。统信 UOS / 麒麟默认只允许「应用商店签名过」的安装包， 我们这类小厂商软件默认被安全策略拦截，需要手动放行一次。

方法 A：用提示里的「前往」按钮放行（推荐，最简单）

  1. 在报错弹窗上点 「前往」（会跳到安全中心）
  2. 依次进入：安全中心 → 安全工具 → 应用安全
  3. 找到「应用安装/运行控制」或「软件安装拦截」，把 「YYWL 键盘配置工具」（或本次安装包）设为 允许 / 信任
  4. 回到安装包，再双击一次即可正常安装

方法 B：安全中心里降低「应用安全」拦截等级

  1. 打开 安全中心（开始菜单里搜索「安全中心」）
  2. 进入 安全工具 → 应用安全
  3. 把「软件安装控制 / 应用安全防护」临时调成 宽松 / 仅提醒（装完可以调回去）
  4. 重新双击安装包安装
⚠️ 如果安全中心的开关是灰色的、改不了：说明贵公司 IT 下发了统一策略。 这时请联系 IT，用下面「情况三」的方式部署（一条命令，之后所有电脑都不用再折腾）。

方法 C：改用「免安装便携版」（不需要安装，绕开签名校验）

  1. 在下载页下载 国产系统 · 便携版（tar.gz）
  2. 解压到任意目录（例如 ~/yywl 或 /opt/yywl）
  3. 双击目录里的 run.sh（或终端执行 bash run.sh）
  4. 如果提示「权限不足/连不上键盘」，按下面「情况二」补一条权限规则

情况一之后：装好了，但双击打不开（没反应）

国产系统默认限制 Electron 的沙箱，程序会「静默退出」——没有报错、也没有窗口。 1.4.12 起的安装包已自动处理（启动参数带 --no-sandbox）。

如果你的版本还打不开，按顺序试：

  1. 终端执行 yywl-config，看是否报错（1.4.12 起已提供该命令）
  2. 或直接完整路径启动： 
    "/opt/YYWL键盘配置工具/yywl-config" --no-sandbox
  3. 仍打不开，把终端输出截图发给技术支持（含报错关键字即可）

或者直接用网页版（最省事）

在浏览器打开 配置页，插上键盘点「连接键盘」即可； 权限规则已由安装包写好，网页和桌面版都能用。

情况二：软件能打开，但点「连接键盘」连不上

这是 Linux 的设备权限问题（不是软件坏了）。装 deb 版会自动配好； 用便携版则需要补一条规则，二选一：

① 双击脚本（需要管理员密码）

  1. 下载 fix-keyboard-permission.sh
  2. 右键 → 属性 → 权限 → 勾选「允许作为程序执行」
  3. 双击运行，弹窗里输入管理员密码（不是 root 密码）
  4. 拔插键盘 USB 线，再点「连接键盘」

② 让 IT 执行一条命令（一次配置，这台机器所有账号都能用）

sudo tee /etc/udev/rules.d/99-yywl-keyboard.rules >/dev/null <<'EOF'
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="413d", MODE="0666"
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="8808", MODE="0666"
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="514c", MODE="0666"
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="1189", MODE="0666"
SUBSYSTEM=="usb", ATTRS{idVendor}=="413d", MODE="0666"
SUBSYSTEM=="usb", ATTRS{idVendor}=="8808", MODE="0666"
SUBSYSTEM=="usb", ATTRS{idVendor}=="514c", MODE="0666"
SUBSYSTEM=="usb", ATTRS{idVendor}=="1189", MODE="0666"
EOF
sudo udevadm control --reload-rules && sudo udevadm trigger
✅ 验证是否生效：终端执行 ls -l /dev/hidraw*， 权限变成 crw-rw-rw- 就对了（拔插键盘后看）。
⚠️ 如果执行时报 No root privileges：说明当前账号不是管理员。 请用管理员账号执行，或让 IT 帮忙。

情况三：公司电脑统一管理（推荐给 IT）

IT 只需要做一次，之后所有同事的电脑都不用再折腾：

做法说明
装机镜像预置 udev 规则 把上面那段规则文件写进镜像的 /etc/udev/rules.d/， 新装的机器天然可访问键盘（浏览器与桌面版都能用）。
内网分发 deb 下载 deb 安装包，内网软件中心/共享盘分发；安装时由管理员密码确认， 安装脚本会自动写 udev 规则。
签名白名单 若贵司启用了强制签名策略，可把我们的包加入信任列表， 或由 IT 用内部证书重签后分发。

还有问题？

把这几样发给我们，定位最快：

  • 系统版本：cat /etc/os-release 的输出
  • 权限状态：ls -l /dev/hidraw* 的输出
  • 软件日志：~/.config/YYWL键盘配置工具/logs/ 里的文件（如果有）
