⚡ Extended Actions Guide

Make one key on your keypad open a folder, open a website, paste a block of text, click a spot on screen — or replay a whole recorded sequence.

Desktop app only Windows / macOS / Linux 1.2.0+
① What it does ② Step 1: create an action ③ Step 2: bind a key ④ Step 3: two saves ⑤ Record a macro ⑥ Trigger keys & conflicts ⑦ Platform differences ⑧ FAQ ⑨ Data & privacy

Start here: three steps

1
Create the action in the “Extended Actions” window Menu File → Extended Actions…. Name a slot, pick an action type, fill in the parameters.
2
Bind that slot to a key on the keypad In the keypad config page, select a key → open the Actions tab → click the matching number (action 1 = F13).
3
Save in both places Save to keypad in the config page, and Save & apply in the actions window.
💡 Shortcut: each slot has quick-template buttons. One click gives you a ready-made action — you only change the folder path or the text.

① What it can do

Extended actions are executed by the desktop app running in the background. The keypad itself only sends keystrokes; the “open / paste / click” part is done by the app.

One slot can hold several steps executed in order, e.g. paste image → wait 300 ms → mouse click → Ctrl+Enter.

Try it: open a folder

1
Click the “Open folder” templateIt is the first button in the template row under the slot.
2
Click “Browse…” and pick the folderThe path is filled in automatically; you can also type it.
3
Give the slot a namee.g. “Open quotes”. The name is shown on the keypad config page so you can tell slots apart.
✅ The name is optional but strongly recommended — without it the config page just shows “Not set”.

The “Test” button

After configuring, click Test to run it once before you continue.

③ Step 2: bind a key

1
Go back to the keypad config pageSelect the physical key you want to use (K1, K2 …).
2
Open the “Actions” tabYou will see numbered buttons: Action 1, Action 2 …
3
Click the matching numberIf the action is in slot 1, click “Action 1”. A toast confirms “Set as extended action 1 (F13)”.
💡 A green ⚡ name on the button means that slot has an action. “Not set” means pressing the key will do nothing.
⚠️ The desktop app must be running in the background. Otherwise the key only sends F13 (or Ctrl+Alt+Shift+F1), which almost no software reacts to — it looks like “nothing happens”.

④ Step 3: two saves (the step people miss)

There are two independent saves. Doing only one is the most common reason “it doesn’t work”:

WhereWhat is savedButton
Keypad config page“Which key is sent”, stored in the keypadSave to keypad
Extended actions window“What the action does”, stored on the PCSave & apply
⚠️ Missing either one breaks it:
· Only saved to keypad → the key reacts, but nothing knows what to do
· Only saved the action → the key still has its old function

After saving to the keypad, some models need to be unplugged and plugged back in before the new config takes effect. Bluetooth models: reconnect once.

⑤ Record a macro

Don’t want to build steps by hand? Just record them. Each slot has a pink ⏺ Record button:

1
Click “⏺ Record”The actions window minimizes automatically so your clicks on it are not recorded.
2
Do the operation onceClick wherever you want, type whatever keys you want — up to 15 seconds.
3
Press F10 to stop earlyOr just wait 15 seconds; the window comes back by itself.

The result becomes normal steps — you can delete, reorder or adjust waits and coordinates afterwards.

RecordedNot recorded / limited
Mouse clicks (with coordinates, left/right/middle)Press-and-drag (becomes two clicks)
Key combos (Ctrl+A, Shift+B …)IME candidate selection
Letters, digits, F1–F12, arrows, Enter/Tab/Space …Mouse wheel
Pauses (≥80 ms becomes a wait step)Ultra-fast taps under ~15 ms (merged)
⚠️ Recording is Windows only for now. On macOS / Linux the button reports “not supported”; add steps manually there.

⑥ Trigger keys & conflicts

⚠️ Once the desktop app registers a trigger key, that key no longer reaches the current application. Do not bind an action to a shortcut you still want to use normally.

The key is already taken by another app

If another program (IME, screenshot tool, chat app …) already owns the combination, the desktop app cannot register it — pressing does nothing and a red banner appears at the top of the window.

1
Click “Check availability”It probes every candidate and tells you which ones are free.
2
Pick a free combination in the slot’s dropdownEntries marked “(in use)” are taken.
3
Save & apply, then re-bind the keyThe keypad must send the new trigger key, so redo step 2.

💡 macOS: on first run, allow the app in System Settings → Privacy & Security → Accessibility. Mouse clicks also need brew install cliclick.
💡 Kylin / UOS: if clicks do nothing, check that you are on an X11 session (echo $XDG_SESSION_TYPE). Wayland restricts simulated input.
💡 There is no Command key on the keypad — that is normal. Win = Command ⌘, Alt = Option ⌥.

⑧ FAQ

Nothing happens when I press the keyCheck in order: ① is the desktop app running (tray icon present) ② did you click “Save to keypad” ③ did you click “Save & apply” ④ does the slot have a name and at least one step ⑤ is there a red “in use” banner?
The action runs but the text is pasted into the wrong windowPaste actions go to whatever window is focused. Click into the target input first, or add a “Mouse click” step before the paste.
The click lands in the wrong placeUsually display scaling (125% / 150%). Re-capture with “📍 Get cursor position” — it uses the same coordinate space as the actual click.
Actions stop working after I close the windowClosing the main window minimizes the app to the tray; it keeps running. To quit completely: right-click the tray icon → Quit. If you quit by accident, just start the app again.
Can it start with Windows?Yes — put a shortcut in the Startup folder (Win+R, type shell:startup).
I changed computers — must I reconfigure?Actions live in actions.json. Use Export / Import in the bottom-right corner. Be careful importing a file from someone else — it may contain “Launch program” steps.
My antivirus complainsExtended actions simulate keyboard and mouse, which some AV products flag. Add the install folder to the whitelist. The app does not connect to the internet or upload anything.
Recorded macros are not accurate enoughRecording samples every ~15 ms, so extremely fast taps may be merged. Record a rough version first, then fine-tune the waits by hand.
