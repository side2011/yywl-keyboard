⚡ 扩展动作使用说明

让键盘上的一个键，帮你打开文件夹、打开网址、粘贴一段文字、点击某个位置，甚至回放一段操作。

桌面版专属 Windows / macOS / Linux 1.2.0 及以上
① 它能做什么 ② 第一步：配动作 ③ 第二步：绑按键 ④ 第三步：两个保存 ⑤ 录制宏 ⑥ 触发键与冲突 ⑦ 各平台差异 ⑧ 常见问题 ⑨ 数据与安全

先看这个：三步就能用起来

1
在「扩展动作」窗口里配好动作 菜单 文件 → 扩展动作… 打开，给某个槽位起名字、选一种动作、填参数。
2
把这个动作绑到键盘上的某个键 到键盘配置页选一个键 → 切到 扩展 选项卡 → 点对应编号（动作 1 就是 F13）。
3
两处都要保存 键盘配置页点 保存到键盘；扩展动作窗口点 保存并生效。
💡 记不住也没关系：扩展动作窗口里每个槽位的「常用模板」按钮，点一下就是一条现成的动作，你只要改改路径或文字。

① 它能做什么

扩展动作是电脑上的桌面版在后台执行的动作。键盘本身只会发按键，真正的"打开、粘贴、点击"都是桌面版帮你做的。

动作参数典型用法
打开文件夹文件夹路径一键打开「报价单」目录
打开网址网址打开公司官网、后台系统
启动程序程序 exe 路径（可带启动参数）启动 ERP 客户端、远程桌面
粘贴文字一段文字（支持换行）一键粘贴收货信息、话术
粘贴图片图片文件路径粘贴签名、印章、产品图
组合键按一下键盘录入，如 Ctrl+Shift+A（可加多组，按顺序发）触发别的软件的快捷键
发送按键（单个键）按一下录入，如 Enter / F5 / Ctrl只想按一个键
按下按键 / 松开按键按键名构造真实按住序列：按下 Ctrl → 按 C → 松开（有些软件不认一次性组合键）
鼠标点击坐标 + 左/右/中键点固定位置的按钮
等待毫秒数等软件反应过来，再执行下一步

一个槽位可以放多个步骤，按顺序执行。比如：粘贴图片 → 等待 300ms → 鼠标点击 → 组合键 Ctrl+Enter。

② 第一步：配置动作

打开方式有两个：顶部菜单 文件 → 扩展动作…，或者键盘配置页「扩展」选项卡里的 ⚙ 配置扩展动作 按钮。

槽位编号是什么意思

一个槽位 = 一个动作 = 一个触发键。窗口里分两栏：

槽位触发键适用硬件
1 – 12F13 ~ F24版本 2.0 新协议键盘
13 – 24Ctrl+Alt+Shift+F1 ~ F12旧协议、蓝牙无线款

动手做一个：打开报价单文件夹

1
点「打开文件夹」模板在槽位下方那排模板按钮里，第一个就是。
2
点「选择…」挑文件夹选好之后路径会自动填进去，也可以手动改。
3
给槽位起名字中间那个输入框，比如写「打开报价单」。这个名字会显示在键盘配置页上，方便你认。
✅ 名称不是必填，但强烈建议填 —— 不填的话，键盘配置页只会显示「未配置」或空白，自己都分不清哪个是哪个。

「测试」按钮

配好后先点 测试，它会立刻执行一遍。没问题再继续。

③ 第二步：把按键绑成触发键

动作配好了，还要告诉键盘「按哪个键触发它」。

1
回到键盘配置页选你要用的那个物理按键（K1、K2…）。
2
切到「扩展」选项卡里面是一排编号按钮：动作 1、动作 2……
3
点一下对应编号比如刚才配在槽位 1，就点「动作 1」。页面上会提示「已设为扩展动作 1（F13）」。
💡 按钮上会显示 ⚡ 动作名（绿色）表示这个槽位已经配了动作；显示「未配置」则说明这个键按下会没反应。
⚠️ 扩展动作必须让桌面版在后台运行。没运行的话，这个键只会发出 F13（或 Ctrl+Alt+Shift+F1），绝大多数软件都不认识，看起来就像"没反应"。

④ 第三步：两个保存（最容易漏的一步）

这里有两个独立的保存，很多人只做了一个，结果发现不生效：

在哪保存的是什么点哪个按钮
键盘配置页「这个键发什么」，写进键盘硬件保存到键盘
扩展动作窗口「动作做什么」，存在电脑上保存并生效
⚠️ 少做任何一个都不生效：
· 只存了键盘 → 按下有反应，但不知道要做什么
· 只存了动作 → 键盘那个键还是原来的功能

保存到键盘之后，有些型号需要拔插一次（或断电重连）才让新配置生效。蓝牙款建议重新连一次。

⑤ 录制宏：不用一步步配

嫌麻烦？直接录一遍就行。槽位右边有个粉色的 ⏺ 录制：

1
点「⏺ 录制」扩展动作窗口会自动最小化（不然会把你点在自己界面上的操作也录进去）。
2
正常操作一遍点哪里、按什么键都行，最多录 15 秒。
3
按 F10 提前结束或者等 15 秒自动结束，窗口会自己弹回来。

录制结果会变成标准步骤，你可以继续改：删掉多余的、改等待时间、改坐标。

能录到录不到 / 有限制
鼠标点击（含坐标、左右中键）按住不放的拖拽（录成两次点击）
组合键（Ctrl+A、Shift+B…）中文输入法的候选词选择
字母、数字、F1–F12、方向键、Enter/Tab/空格等鼠标滚轮
操作之间的停顿（≥80ms 记成等待）比 15ms 还快的极速连点（会合并）
⚠️ 录制目前只支持 Windows。macOS / Linux 上点录制会提示不支持，需要手动加步骤。

⑥ 触发键与冲突

桌面版要"接管"这些触发键才能执行动作，所以有个副作用：

⚠️ 一旦某个触发键被桌面版接管，按下它就不会再传给当前软件。所以不要把动作配到一个你还要当快捷键用的组合上。

被别的软件占用了怎么办

如果这个键已经被其它程序（输入法、截图工具、QQ、微信…）注册过，桌面版就抢不到。表现是按下没反应，窗口顶部会出现红色提示。

解决办法：

1
点右下角「检测占用」它会挨个试一遍，告诉你哪些组合是空闲的。
2
在槽位右边换成空闲的组合下拉框里带「（被占用）」的别选，换一个没标记的。
3
点「保存并生效」然后重新在上面三步里绑一次按键（因为键盘发的键也变了）。

⑦ 各平台差异

WindowsmacOS国产 Linux
打开/粘贴/组合键✅✅✅
鼠标点击✅ 原生需要 cliclick需要 xdotool
宏录制✅❌❌
额外要求杀毒软件可能拦模拟输入需授权「辅助功能」需 X11，Wayland 有限制
💡 macOS 首次运行会提示授权：系统设置 → 隐私与安全性 → 辅助功能，把「YYWL 键盘配置工具」勾上。鼠标点击还需要终端执行 brew install cliclick。
💡 国产系统（麒麟 / UOS）如果点击无效，先确认当前是 X11 会话（echo $XDG_SESSION_TYPE），Wayland 下模拟输入受限制。
💡 键盘上没有 Command 键是正常的：Win 就是 Command ⌘，Alt 就是 Option ⌥。

⑧ 常见问题

按了没反应按顺序排查：① 桌面版在没在运行（看托盘有没有图标）② 键盘配置页有没有「保存到键盘」③ 扩展动作窗口有没有「保存并生效」④ 槽位名称是不是空的、步骤是不是空的 ⑤ 顶部有没有红色"被占用"提示。
动作执行了，但粘贴的内容跑到别的窗口去了粘贴类动作会粘到"当前前台窗口"。执行前先点一下目标窗口的输入框。也可以在前面加一个「鼠标点击」步骤，先点住输入框再粘贴。
鼠标点击的位置偏了多半是显示器缩放（125% / 150%）造成的。用「📍 取鼠标位置」重新录一次坐标，它和真正点击用的是同一套坐标，能自动对上。
关掉窗口后动作就不灵了关闭主窗口后程序会缩到托盘继续运行，这是正常的。要彻底退出：右键托盘图标 → 退出。如果不小心退出了，重新打开程序即可。
能不能开机自动启动可以：把程序的快捷方式放进「启动」文件夹（Win+R 输入 shell:startup）。
换电脑了，动作要重配吗动作存在 actions.json 里，用窗口右下角的 导出 / 导入 搬过去就行。注意导入的文件来自别人时要小心 —— 里面可能包含"启动程序"这类动作。
杀毒软件报警了扩展动作会模拟键盘鼠标，部分杀软会敏感。把安装目录加入白名单即可。程序不联网、不上传任何内容。
键鼠宏录出来不准录制是每 15ms 采样一次，特别快的连点可能被合并。复杂操作建议：先录个大概，再手动微调等待时间。

⑨ 数据与安全

会不会写进键盘不会。键盘里只存"这个键发 F13"，动作本身永远在电脑上
