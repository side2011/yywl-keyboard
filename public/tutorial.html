💻0. 用网页版还是桌面版

🌐 网页版（推荐）

key.itytsoft.com/ws/
  • 打开即可用，无需安装
  • 需要 Chrome 89+ / Edge 89+
  • 需要能访问外网
  • 浏览器会弹出系统级的设备选择框

🖥️ 桌面版（内网 / 离线）

Windows · macOS · Linux
  • 整个网页打包进程序，完全离线
  • 双击即用，不用装浏览器

💡 两种方式的配置数据不互通：网页版的"配置方案"存在浏览器里，桌面版存在程序自己的目录里。跨设备迁移请用「导出 JSON / 导入 JSON」。

🔍1. 先分清你的键盘是哪一代

这一点很重要，因为三代的配置界面和可调项完全不同。最省事的办法：直接连上去，工具会自动识别并跳到对应页面。下表用来对照确认。

① 旧协议款

VID 0x8808
  • 1～12 键常规款、旋钮款、方向键、脚踏、Plus 系列
  • 单层配置
  • 有灯光 / 延迟（按型号不同）

② 版本 2.0（新协议）

VID 0x514C
  • 连上后型号显示为 「版本2.0」
  • 支持多层、宏录制、一键密码
  • 还有麦克风款、方向键款、旋钮款

③ 蓝牙无线款

VID 0x1189 / 0x514C
  • 带电池、支持蓝牙/无线接收器
  • 最多 3 层（V10 固件）
  • 有旋钮的型号每只占 3 个槽位
⚠️ 怎么快速区分？
· 连接后自动跳到紫色配置页且能看到「层」切换 → 新协议或多层型号
· 连接后跳到蓝色配置页、只有一排按键 → 旧协议款
· 连接时提示"未检测到键盘"或"检测到蓝牙无线款" → 多半是蓝牙款，见第 5 章
🆕 以后新型号都会走"版本 2.0"协议，所以新买的键盘基本都在第 4 章；老款（尤其是已经出货多年的）继续用第 3 章，两边都会长期兼容。

🔌2. 连接键盘

1

准备工作

① 用 USB 数据线把键盘接到电脑（必须走 USB，蓝牙模式下无法配置）
② 用 Chrome 89+ 或 Edge 89+ 打开工具
③ 关闭其它占用键盘的程序（旧的配置软件、别的浏览器标签）

⚠️ 不支持 Safari、Firefox、IE，以及微信/QQ/钉钉内置浏览器。
⚠️ 在应用内嵌窗口（如编辑器预览面板）里打开会连不上——这类窗口没有设备选择框，请复制地址到系统 Chrome/Edge 独立标签页打开。
2

点「连接键盘」并选择设备

浏览器会弹出系统级设备选择框，选中你的键盘（名字通常含 YYWL）→ 点「连接」。

💡 列表里出现"未知设备"是正常的，选中即可，连上后自动识别型号。
💡 列表里看不到设备？点按钮下方的「找不到设备？列出全部同厂设备」，会把该厂商所有接口都列出来。
❌ 没弹框、直接提示"未检测到键盘设备"：通常是没插线，或插的是无线接收器（接收器只做数据传输，不能被配置）。请插键盘本体的 USB 线。
3

连上之后

页面顶部会显示型号、按键数、层数等信息，然后自动跳到对应的配置页。若型号未识别，会出现手动选择型号的下拉框，选对即可。

⌨️3. 旧协议款配置 单层 · 经典界面

适用于 1～12 键常规款、旋钮款、方向键、脚踏、4 键侧插、Plus 系列等 0x8808 设备。

🎯 四种功能模式

⌨️ 键盘

模拟键盘按键，可叠加修饰键（Ctrl / Shift / Alt / Win，左右可分别选）。
例：Ctrl+C 复制、Win+D 显示桌面、Alt+F4 关闭窗口

🖱️ 鼠标

模拟鼠标动作：左/右/中键、X/Y 位移、滚轮。
例：设为左键＝单击；X=10 且 Y=0＝每次右移 10 像素

🎵 多媒体

一键触发系统媒体功能，共 20 种：播放/暂停、上下曲、音量±、静音、亮度±、计算器、浏览器、邮件、刷新/前进/后退等。

🔗 多键合一

按一次自动顺序输出一串按键，可带修饰键，用于输入固定文本/密码。
上限：按型号 7～50 个（页面会显示剩余可加数量）

🎯 快捷键捕获（强烈推荐）

① 选中要配置的按键（如 K1）点左侧按键卡片
② 点「🎯 捕获按键」按钮，按钮开始闪烁等待捕获
③ 在电脑键盘上直接按目标组合键如 Ctrl + C
④ 自动填好修饰键与按键码按 Esc 取消

🌈 灯光设置

配置页右下方是灯光区域，不同型号的灯效表不同（15 种是常见配置）：灯光关闭、按下亮（红/绿/蓝/黄/青/紫/白）、流水 1/2/3、放射、常亮、台灯、自定义颜色等。

💡 选「自定义颜色」后可点取色器调 RGB；
💡 双灯区型号（2 键 Plus / 3 键 Plus / 旋钮+4 键）有两个颜色区，分别对应主键区与副灯区；
💡 7 键无灯款、脚踏开关没有灯光，界面不会显示灯光区域，属正常。

⏱️ 延迟时间（部分型号）

为每个按键单独设延迟（0～60000 ms）。主要配合「多键合一」控制每步之间的间隔。

✅ 支持：1/2/3/4/5/6 键、2 键迷你、5 键触摸、8 键新款、8 键开关款、10 键定制、2 键 Plus、3 键 Plus、3 键定制、方向键
❌ 不支持：7 键（含无灯）、8 键旧款、9 键、12 键、旋钮、DIY 10 键、旋钮+4 键、4 键侧插（新旧）、脚踏
💾

保存到键盘

配置完成后点左侧的「保存到键盘」。写入成功会弹绿色提示；配置存在键盘内部闪存，断电不丢，换电脑也不影响。

💡 想确认写进去没有：点「读取配置」从键盘回读一次，界面显示的就是键盘里真实保存的内容。

✨4. 版本 2.0（新协议）配置 多层 · 宏 · 一键密码

适用于 0x514C 的新固件设备：连上后型号显示为「版本2.0」，支持多层、宏、一键密码。以后的新型号都会走这套协议。

💡 页面顶部会显示从键盘读到的真实参数：按键数、旋钮数、层数、布局类型。这些是键盘自己上报的，不用手选。

🗂️ 多层配置

层（Layer）相当于"几套配置同时存在键盘里"，可以用某个键切层——例如一层办公、二层游戏。

📌 层操作

切换当前编辑的层点顶部「层 1 / 2 / 3 …」
保存「保存到键盘」→ 所有层一次性写入
灯光灯光配置会同时应用到所有层
⚠️ 层数由键盘上报（1～16 层，常见 1～3 层）。只有 1 层的设备不会显示层切换，属正常。

🎬 宏（多键合一升级版）

宏是一串可带延时的按键动作序列，支持按下/松开分离，能做出组合键、连招、自动输入等效果。

📌 两种录入方式

① 录制：点「开始录制」，依次按电脑键盘自动生成步骤
② 手动插入：从虚拟键盘选键，插入到选中步骤后不录制也能拼
调整步骤顺序 / 单个延时上移 · 下移 · 删除
清空「清空步骤」
💡 修饰键（Ctrl/Shift/Alt/Win）在宏里是独立步骤，所以要"按住→再按字母→再松开"。
💡 单键上设置宏后，该键的模式会自动切成「宏」。

🔑 一键密码

在宏标签页下方的输入框里直接输入要输出的文本（如邮箱、密码），程序会自动把每个字符翻译成 HID 按键步骤追加进宏——大小写、数字、常用符号（含 Shift 组合）都支持。

💡 适合"一键登录""一键填地址"。生成后仍然可以继续手动增删步骤。
⚠️ 密码会明文保存在配置里，公用电脑请注意。

🌈 灯光

新版灯效表与旧协议不同，常见 10 种：关闭、常数、流光、按键触发、彩虹流光、波浪、彩虹跑马、呼吸、涟漪、交叉涟漪。

💡 保存灯光时会逐层写入，避免出现"只关了当前层灯光、其他层还亮着"的情况。

🧭 特殊型号

方向键款（十字布局）

按键按上下左右十字排列，与实物一致：K1=上、K2=左、K3=下、K4=右。

旋钮款

旋钮的左转 / 按下 / 右转各占一个槽位，界面按实物位置排布。

💾

保存到键盘

点「保存到键盘」后，程序会逐层写入并做最终提交。过程中顶部会显示进度，请勿拔线。

⚠️ 写入需要几秒到十几秒（层数越多越久），期间拔线可能导致该层写入失败，重连后再保存一次即可。

📡5. 蓝牙无线款配置 专用软件 / 网页蓝牙页

蓝牙无线款（带电池、支持蓝牙连接或 2.4G 接收器）用的是另一套协议，配置入口有两个：

方式一：网页蓝牙页（新版）

/ws/ → 自动跳转「蓝牙配置」
  • 连上后自动识别并跳到蓝牙配置页
  • 支持键位、多媒体、鼠标、宏、灯光
  • V10 固件支持 3 层

方式二：专用桌面软件

老款 / 网页不支持的型号
  • 老型号或特殊固件请用专用软件
  • 软件由客服按型号提供
  • 同样走 USB 配置，不是蓝牙连接
⚠️ 配置必须走 USB 线。蓝牙连接状态下系统只把它当普通输入设备，不开放配置通道。所以无论用哪种方式，都请先用数据线把键盘接到电脑。

🎛️ 槽位与旋钮

蓝牙款里，每个旋钮占 3 个槽位：左转、按下、右转。界面上显示为 旋钮1左 / 旋钮1中 / 旋钮1右。不带旋钮的型号只有普通按键槽位。

🗂️ 层

· V10 固件（版本 ≥ 10）：3 层，可切换编辑，保存时逐层写入
· 旧固件（版本 < 10）：1 层，不显示层切换，属正常

🎯 可配置的功能

⌨️ 键盘

修饰键 + 按键，和旧协议一致

🖱️ 鼠标

按键、滚轮、移动、滑动方向

🎵 多媒体

播放控制、音量、亮度、浏览器等

🎬 宏 / 多键

按型号支持；步骤可带延时

⚠️ 蓝牙款写入后需要几秒把配置刷进闪存，保存成功后请等 2～3 秒再拔线，否则可能丢配置。

🎤6. 麦克风款

带麦克风的复合款小键盘会被自动识别，并跳转到麦克风配置引导页——这类设备的麦克风部分需要用专用软件设置，不能用网页工具改。

💡 引导页里有：使用教程视频、Windows / macOS 专用软件下载、客服联系方式。
💡 判断方法：连上后页面直接跳到麦克风引导页，说明检测到麦克风款。

🖥️7. 桌面版与内网部署

桌面版把整个网页打包进程序，不联网也能用，适合内网电脑、车间电脑、演示机。

📌 使用步骤

① 打开下载页key.itytsoft.com/ws/download.html
② 页面会自动识别你的系统并高亮对应版本Windows / macOS / Linux
③ 下载后解压（Windows 是免安装绿色版）双击 .exe 直接运行
④ 插上键盘 → 点「连接键盘」无需选择设备
⚠️ Windows 首次运行可能弹"未知发布者"（SmartScreen），点「更多信息」→「仍要运行」即可。
⚠️ macOS 首次打开未签名程序会被拦，右键程序 →「打开」→ 再点「打开」。
💡 桌面版与网页版界面完全一致，配置方式也一样，只是不用浏览器。
💡 内网批量部署：把解压后的整个文件夹拷到目标电脑即可，无需安装、无需管理员权限。

❓9. 常见问题

Q1：点「连接键盘」没有任何弹框，只提示"未检测到键盘设备"

① 确认插的是键盘本体的 USB 线，不是无线接收器（接收器不能被配置）；
② 关掉其它占用键盘的程序（旧配置软件、别的浏览器标签）；
③ 拔插一次 USB 再试；
④ 点按钮下方的「找不到设备？列出全部同厂设备」；
⑤ 如果是在应用内嵌窗口里打开的，请复制地址到系统 Chrome/Edge 独立窗口。

Q2：弹出"检测到蓝牙无线款，请下载专用软件"

说明当前设备走的是蓝牙款协议且该型号还没被网页支持，按提示下载专用软件即可。若你的键盘其实支持网页配置，先确认是用 USB 线连接，并升级到最新固件。

Q3：连接后型号显示「未识别」怎么办？

在设备信息区域会出现手动选择型号的下拉框，选对应型号即可。选择后配置项会按该型号的能力显示。

Q4：保存后灯光/按键没有变化

① 点「读取配置」从键盘回读，确认真的写进去了；
② 某些型号灯光需要选中「自定义颜色」并单独下发颜色，先切到其它模式保存一次再切回来；
③ 多层设备确认改的是当前层，以及是否点了「保存到键盘」。

Q5：为什么我没有「层」切换、也没有「延迟」设置？

这两个能力由硬件/固件决定。单层型号不显示层切换；不支持延迟的型号不显示延迟区域。参考第 8 章速查表。

Q6：配置会丢吗？换电脑还有效吗？

配置写在键盘内部闪存里，断电不丢，换电脑、重装系统都不影响。网页上的"配置方案"另存在浏览器本地，换电脑请用导出/导入 JSON。

Q7：网页版和桌面版可以同时用吗？配置会互相覆盖吗？

可以同时装，但不要同时连接同一把键盘——两个程序争用设备会连不上。配置方案的存储彼此独立，需要迁移就用 JSON 导出导入。

Q8：Linux 下连不上

需要给 hidraw 加 udev 权限。工具里会给出可直接复制的命令，或下载 fix-keyboard-permission.desktop 双击执行；执行完拔插一次键盘。

Q9：按键测试怎么用？

在连接页或配置页点「🎯 按键测试」进入测试界面，按键盘上的键会实时高亮并显示该键当前配置的功能，还能看原始 HID 数据——排查"键不生效"最快的方法。

Q10：多键合一/宏最多几步？

旧协议按型号 7～50 步；新协议与蓝牙款按 macros 容量而定（页面会显示已用步数）。超出时保存会失败并提示。
