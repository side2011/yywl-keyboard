平台步骤
Windows解压 zip → 双击 YYWL键盘配置工具.exe（免安装，不用管理员权限）

🀄 国产操作系统（信创）用户

麒麟、统信 UOS、深度等国产系统本质上是 Linux，但直接跑 AppImage 经常起不来 （缺 FUSE、/home 被设成 noexec、系统禁用了 user namespace 导致沙箱报错）。 所以这里单独做了 国产系统便携版：解压即用，不用安装、不用 FUSE、不依赖沙箱。

② 运行国产系统便携版（推荐）

解压后进目录，执行下面两步（第一步只需做一次，会要一次管理员密码）：

# 1) 配置键盘访问权限（只需一次） ./install-hid.sh # 2) 启动 ./run.sh

双击 run.sh 选「在终端中运行」也可以。包内附 README-国产系统.txt， 含 noexec / 闪退 / 连不上键盘等问题的处理办法。

③ 如果你更习惯 AppImage

通用 Linux 版仍提供 AppImage，但它依赖系统有 FUSE；缺 FUSE 时加参数绕过：

chmod +x yywlkey-config-1.0.0-linux-x64.AppImage ./yywlkey-config-1.0.0-linux-x64.AppImage --appimage-extract-and-run
⚠️ 国产系统上的常见问题
· 安全中心拦截：麒麟/UOS 的「安全中心」「应用防护」可能拦截未知程序，需在弹窗里选「允许」或加白名单。
· 提示 noexec：/home 被设成禁止执行程序（等保加固常见），按 run.sh 的提示把目录拷到 /opt 即可，只需一次管理员密码。
· 连不上键盘：先跑 ./install-hid.sh（写 udev 规则），再拔插一次键盘。
· 龙芯（loongarch64）：Electron 暂无官方支持，请把 uname -m 结果发给我们。

⚡ 扩展动作（桌面版专属）

键盘本身只能发标准按键，做不到打开文件夹、开网址、粘贴一段文字或图片、按坐标点击鼠标。 这些由桌面版的后台程序监听一个"保留热键"来完成——所以桌面版必须在后台运行。

能做什么说明
打开文件夹 / 文件一键打开报价单目录、模板文件等
打开网址打开公司系统、常用网页
粘贴文字地址、单号、整段话（支持中文，走剪贴板粘贴）
粘贴图片把签名图、产品图直接粘到微信/Word 里
鼠标点击 + 组合键按坐标点击后再按 Ctrl+Enter 等，可多步串联
🖥 网页版看不到这个功能——浏览器无法监听全局按键，也不能操作鼠标键盘。
需要的话请下载桌面版：装好后在菜单 文件 → 扩展动作 里配置，程序会自动最小化到托盘常驻。
⚠️ 首次使用注意：macOS 会要一次「辅助功能 / 输入监控」授权；国产 Linux 需要 X11 会话（Wayland 下模拟输入受限）； 部分安全软件可能拦截模拟输入，需加白名单。
