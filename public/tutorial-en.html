User Guide

A complete step-by-step guide to configure all YingYu IoT multi-function keypads

Models: 1-Key to 12-Key / Knob / Foot Switch / Arrow Keys and more
!

📡Bluetooth Wireless Users Please Note

If you are using a Bluetooth wireless keypad, this web tool does not support configuration. Bluetooth models require a dedicated desktop configuration software. Please click the button below to download:

Download Bluetooth Config Software
Bluetooth wireless models have VID 0x1189 or 0x514C. If you are unsure of your model, try connecting first -- the system will auto-detect and notify you.
1

🔌Preparation

Before getting started, make sure you meet the following requirements:

Browser: Chrome 89+ or Edge 89+ (must support WebHID API)
Device: Keypad connected to computer via USB cable
Network: Able to access this web tool
Safari, Firefox, and some regional browsers (e.g. 360, QQ Browser) are NOT supported.
The built-in Edge browser on Windows works fine. macOS users should install Chrome or Edge.
2

🔗Connect the Keypad

Open your browser and go to key.itytsoft.com/ws/, then click the "Connect Keyboard" button in the center of the page.

A device selection window will appear. Choose YYWL-Keyboard or the corresponding device name from the list, then click "Connect".

If "Unknown Device" appears in the list, you can still connect and then manually select the correct model.
After a successful connection, you will be redirected to the config page. The device model and key count will be shown at the top.
3

⌨️Configure Key Functions

On the config page, the left side shows the physical keys (K1 ~ Kn, count depends on your model), and the right side is the function settings area.

Steps:

1. Click any key on the left (e.g. K1) to select it
2. Choose a function mode on the right and set the parameters
3. Switch to the next key and continue configuring

Four Function Modes

Keyboard Mode

Simulate keyboard keystrokes. Combine with modifier keys (Ctrl / Shift / Alt / Win, multi-select), then pick a key.

Examples: Ctrl+C (Copy), Win+D (Show Desktop), Alt+F4 (Close Window)

Mouse Mode

Simulate mouse actions. Set mouse button (Left/Right/Middle) and X/Y movement, scroll value.

Examples: Left click = mouse click, X=10 Y=0 = move right

Media Mode

Trigger multimedia functions like play/pause, volume control, open browser, etc.

Options: Play/Pause, Volume +/-, Mute, Calculator, Browser, Brightness and 20 more functions

Multi-Key Mode

Press once to send a sequence of keystrokes (configurable length), optionally with modifiers.

Examples: Auto-type email address, auto-enter password, one-click shortcut text

🎯 Key Capture Feature

Don't want to hunt for keys on the virtual keyboard? Try the Capture Key feature! Just press the key you want on your physical keyboard and it's automatically configured.

Steps:
① Select the keypad key to configure (e.g. K1)
② Click the "🎯 Capture Key" button in the Keyboard mode area
③ When the button turns yellow and pulses, press your target key on the physical keyboard (supports Ctrl/Shift/Alt/Win combos)
④ The key is automatically captured and configured! Press Esc to cancel

💡 Example: To set Ctrl+C (Copy), click Capture then press Ctrl+C on your keyboard — modifiers and key code are detected automatically.
4

💡Light Settings

The light settings area is at the bottom-right of the config page. Available light modes vary by model. Common modes include:

Common modes: Light Off, Press-Lit (Red/Green/Blue/Yellow/Cyan/Purple/White), Flow modes, Always On, Lamp Mode, Custom Color, etc.

After selecting "Custom Color" mode, click the color picker to set a custom RGB value.

Some models (e.g. 7-Key No-LED) do not support lighting. In that case, the light settings area will not be shown.
5

⏱️Delay Time Settings (select models)

Some models support per-key delay time (in milliseconds). This is especially useful in Multi-Key mode -- it controls the interval between keystrokes in the sequence.

Models that support delay:
1-Key 2-Key 2-Key Mini 3-Key 4-Key 5-Key 6-Key 5-Key Touch 8-Key New 8-Key Switch 10-Key Custom 2-Key Plus 3-Key Plus 3-Key Custom Arrow Keys
Models that do NOT support delay:
7-Key (incl. No-LED), 8-Key (old), 9-Key, 12-Key, Knob, DIY 10-Key, Knob+4-Key, 4-Key Side-Plug (old/new), Foot Switch

These models will not show the delay settings area after connection, which is normal.
If your model supports delay, enter the millisecond value (0~60000ms) for each key in the "Delay Time" area on the left.
Set to 0 for no delay. Set to 500 to wait 500ms before triggering the next key.
6

💾Save Config to Keyboard

After configuring all keys, click the "Save to Keyboard" button (the gradient blue-purple button) in the operation area on the left. The config will be written to the keyboard's internal storage.

A green "Config saved to keyboard successfully!" toast will appear upon success.
Config is stored in the keyboard's flash memory -- it survives power loss and works across different computers.
You can also click "Read Config" to read back the current saved settings from the keyboard.
7

8

🎯Key Test

After configuring, use the Key Test feature to verify that each key works as expected. Click the "Key Test" button on the connection page or config page top bar to enter the test interface.

Features:
1. Press any key on the keypad -- the test interface highlights the pressed physical key in real time
2. Automatically shows the configured function for that key (Keyboard / Mouse / Media / Multi-Key)
3. Displays raw HID data (ReportID, length, HEX dump) for debugging
4. Event log records recent key presses with a one-click clear option
Use case: After saving your config, use Key Test to quickly verify each key's trigger effect without switching to another application.
The test interface automatically reads the current config saved on the keyboard and displays each key's assigned function.

❓FAQ

Q: It shows "Unknown Device" after connecting. What should I do?

This is normal and does not affect usage. After connecting, a manual model selection dropdown will appear in the device info area. Simply select your model.

Q: The light mode didn't change after saving?

Click "Read Config" to re-read from the keyboard and check if the light mode dropdown shows correctly. If the issue persists, try saving a different mode first, then switch back to the desired mode and save again.

Q: What is the maximum number of keys in Multi-Key mode?

The maximum sequence length varies by model (typically 7~50 keys). The exact limit is shown next to the key sequence on the config page. Click the virtual keyboard to add keys, and click x to remove them.

Q: Will the config be lost?

Config is stored in the keyboard's internal flash memory and survives power loss. Switching computers or reinstalling the OS does not affect the keyboard config. Web-based config profiles are saved in browser local storage.

Q: Why doesn't my keyboard have delay time settings?

Not all models support the delay time feature. Refer to the "Model Feature Reference" table above to check if your model supports it. Models without support will not show the delay settings area, which is expected.

Q: Can I use this tool with a Bluetooth wireless model?

Bluetooth wireless models require dedicated configuration software. This web tool does not support them.
