🔍1. Identify Your Keyboard Generation

This matters because the three generations have completely different configuration screens and adjustable options. The simplest approach: just connect the keyboard — the tool detects it and jumps to the right page. Use the table below to confirm.

① Legacy Protocol

VID 0x8808
  • 1–12-key standard, Knob, Arrow keys, Foot pedal, Plus series
  • Single-layer configuration
  • Lighting / delay (depending on model)

② Version 2.0 (New Protocol)

VID 0x514C
  • After connecting, the model shows as "Version 2.0"
  • Supports multiple layers, macro recording, and one-key password
  • Also includes microphone, arrow-key, and knob models

③ Bluetooth Wireless

VID 0x1189 / 0x514C
  • Built-in battery, supports Bluetooth / wireless receiver
  • Up to 3 layers (V10 firmware)
  • Each knob occupies 3 slots
⚠️ How do you tell them apart quickly?
· After connecting, it jumps to the purple config page and shows a "Layer" switch → new protocol or multi-layer model
· After connecting, it jumps to the blue config page with just one row of keys → legacy protocol model
· If connecting shows "No keyboard detected" or "Bluetooth wireless model detected" → most likely a Bluetooth model; see Chapter 5
🆕 All future models will use the "Version 2.0" protocol, so newly purchased keyboards are almost all covered in Chapter 4; older models (especially those shipped years ago) keep using Chapter 3. Both are supported long-term.

🔌2. Connect the Keyboard

Before You Start

① Connect the keyboard to your computer with a USB data cable (USB is required — configuration does not work in Bluetooth mode)
② Open the tool in Chrome 89+ or Edge 89+
③ Close other programs that use the keyboard (old configuration software, other browser tabs)

The browser opens the system-level device picker. Select your keyboard (its name usually contains YYWL) → click "Connect".

💡 Don't see your device in the list? Click "Can't find your device? List all vendor devices" below the button to list every interface from that vendor.
❌ No dialog — just "No keyboard device detected": usually the cable isn't plugged in, or you plugged in a wireless receiver (a receiver only transfers data and cannot be configured). Plug the USB cable into the keyboard itself.
3

After Connecting

The top of the page shows the model, key count, layer count, and other details, then jumps to the matching configuration page. If the model isn't recognized, a Select model manually dropdown appears — pick the right one.

⌨️3. Legacy Protocol Configuration Single layer · Classic UI

Applies to 0x8808 devices such as 1–12-key standard, Knob, Arrow keys, Foot pedal, 4-key side-plug, and Plus series.

🎯 Four Function Modes

⌨️ Keyboard

Emulates keyboard keys, with optional modifier keys (Ctrl / Shift / Alt / Win, left and right selectable separately).
Examples: Ctrl+C to copy, Win+D to show the desktop, Alt+F4 to close a window

🖱️ Mouse

Emulates mouse actions: left/right/middle button, X/Y movement, scroll wheel.
Examples: set to left button = single click; X=10 and Y=0 = move 10 pixels right each time

🎵 Multimedia

Triggers system media functions with one key — 20 in total: play/pause, previous/next track, volume ±, mute, brightness ±, calculator, browser, email, refresh/forward/back, and more.

🔗 Multi-key Combo

Press once to output a sequence of keys in order, with optional modifiers — useful for typing fixed text or passwords.
Limit: 7–50 steps depending on model (the page shows how many you can still add)

🎯 Shortcut Capture (Highly Recommended)

① Select the key to configure (e.g. K1)Click the key card on the left
② Click "🎯 Capture Key" — the button starts blinkingWaiting to capture
③ Press the target key combination on your computer keyboarde.g. Ctrl + C
④ Modifiers and key code are filled in automaticallyPress Esc to cancel

🌈 Lighting Settings

The lighting area is at the bottom right of the configuration page. Available effects differ by model (15 is the common set): lighting off, light on press (red/green/blue/yellow/cyan/purple/white), flow 1/2/3, radial, steady, desk lamp, custom color, and more.

💡 After choosing "Custom color", click the color picker to adjust RGB;
💡 Dual lighting-zone models (2-key Plus / 3-key Plus / Knob+4-key) have two color zones, one for the main keys and one for the secondary light zone;
💡 The 7-key no-light model and the Foot pedal have no lighting, so no lighting area is shown — this is normal.

⏱️ Delay Time (Some Models)

Set a delay for each key individually (0–60000 ms). Mainly used with "Multi-key Combo" to control the interval between steps.

✅ Supported: 1/2/3/4/5/6-key, 2-key Mini, 5-key touch, 8-key new, 8-key switch, 10-key custom, 2-key Plus, 3-key Plus, 3-key custom, Arrow keys
❌ Not supported: 7-key (including no-light), 8-key old, 9-key, 12-key, Knob, DIY 10-key, Knob+4-key, 4-key side-plug (old and new), Foot pedal
💾

Save to Keyboard

When you're done, click "Save to Keyboard" on the left. A green confirmation appears on success; the configuration is stored in the keyboard's internal flash, survives power loss, and is unaffected by switching computers.

💡 To confirm it was written: click "Read Config" to read it back from the keyboard — what the interface shows is what is actually stored in the keyboard.

✨4. Version 2.0 (New Protocol) Configuration Multi-layer · Macros · One-key password

Applies to 0x514C devices with the new firmware: after connecting, the model shows "Version 2.0" and supports multiple layers, macros, and one-key password. All future models will use this protocol.

💡 The top of the page shows the real parameters read from the keyboard: key count, knob count, layer count, layout type. These are reported by the keyboard itself — no manual selection needed.

🗂️ Multi-Layer Configuration

A layer is like "several configurations living in the keyboard at once"; you can switch layers with a key — for example, layer 1 for office work and layer 2 for gaming.

📌 Layer Operations

Switch the layer being editedClick "Layer 1 / 2 / 3 …" at the top
Save"Save to Keyboard" → all layers written at once
LightingLighting settings are applied to all layers
⚠️ The layer count is reported by the keyboard (1–16 layers; 1–3 is common). Devices with only 1 layer show no layer switch — this is normal.

🎬 Macros (Upgraded Multi-key Combo)

A macro is a sequence of key actions that can include delays. Press and release are separate steps, so you can create key combos, combo chains, automated typing, and more.

📌 Two Ways to Enter Steps

① Record: click "Start Recording" and press the keys on your computer keyboard in orderSteps generated automatically
② Insert manually: pick keys from the virtual keyboard and insert them after the selected stepBuild it without recording
Reorder steps / adjust a single delayMove up · Move down · Delete
Clear"Clear Steps"
💡 Modifier keys (Ctrl/Shift/Alt/Win) are separate steps in a macro, so you "hold → press the letter → release".
💡 Once a macro is set on a key, that key's mode switches to "Macro" automatically.

🔑 One-Key Password

In the input box below the Macro tab, type the text you want to output (such as an email address or password). The program converts each character into HID key steps and appends them to the macro — upper and lower case, digits, and common symbols (including Shift combinations) are all supported.

💡 Great for "one-key login" and "one-key address fill". You can still add or remove steps manually afterwards.
⚠️ The password is stored in plain text in the configuration — be careful on shared computers.

🌈 Lighting

The new lighting effect table differs from the legacy protocol. There are 10 common effects: off, constant, flow, key press, rainbow flow, wave, rainbow marquee, breathing, ripple, cross ripple.

💡 Lighting is saved layer by layer, so you never end up with "only the current layer's lighting turned off while the other layers stay lit".

🧭 Special Models

Arrow-Key Model (Cross Layout)

Keys are arranged in a cross (up / down / left / right) matching the hardware: K1=Up, K2=Left, K3=Down, K4=Right.

Knob Model

Left turn / press / right turn each occupy a slot, and the interface follows the hardware layout.

💾

Save to Keyboard

After clicking "Save to Keyboard", the program writes layer by layer and commits at the end. Progress is shown at the top during the process — do not unplug the cable.

⚠️ Writing takes a few seconds to a dozen or so seconds (more layers take longer). Unplugging during the write may cause that layer to fail; reconnect and save again.

📡5. Bluetooth Wireless Configuration Dedicated software / Web Bluetooth page

Bluetooth wireless models (with a battery, supporting Bluetooth or a 2.4G receiver) use a different protocol. There are two ways to configure them:

Option 1: Web Bluetooth Page (New)

/ws/ → automatically opens "Bluetooth Configuration"
  • Detected automatically after connecting and redirected to the Bluetooth configuration page
  • Supports keys, multimedia, mouse, macros, and lighting
  • V10 firmware supports 3 layers

Option 2: Dedicated Desktop Software

Older models / models the web version doesn't support
  • Use the dedicated software for older models or special firmware
  • Software is provided by customer support based on your model
  • Also configured over USB, not over Bluetooth
⚠️ Configuration must be done over a USB cable. While connected over Bluetooth, the system treats the keyboard as a plain input device and does not expose the configuration channel. So whichever option you use, connect the keyboard to your computer with a data cable first.

🎛️ Slots and Knobs

On Bluetooth models, each knob occupies 3 slots: left turn, press, right turn. They appear in the interface as Knob 1 Left / Knob 1 Middle / Knob 1 Right. Models without a knob only have regular key slots.

🗂️ Layers

· V10 firmware (version ≥ 10): 3 layers, switchable for editing, written layer by layer when saving
· Older firmware (version < 10): 1 layer, no layer switch shown — this is normal

🎯 Configurable Functions

⌨️ Keyboard

Modifiers + keys, same as the legacy protocol

🖱️ Mouse

Buttons, scroll wheel, movement, swipe direction

🎵 Multimedia

Playback controls, volume, brightness, browser, and more

🎬 Macro / Multi-key

Supported depending on model; steps can include delays

⚠️ Bluetooth models need a few seconds after writing to flush the configuration into flash. Wait 2–3 seconds after a successful save before unplugging, otherwise the configuration may be lost.

🎤6. Microphone Models

Composite keypads with a microphone are detected automatically and redirected to the microphone configuration guide page — the microphone part of these devices must be set up with dedicated software and cannot be changed with the web tool.

💡 The guide page includes: tutorial videos, Windows / macOS dedicated software downloads, and support contacts.
💡 How to tell: after connecting, the page jumps straight to the microphone guide, which means a microphone model was detected.

❓9. FAQ

Q1: Clicking "Connect Keyboard" shows no dialog — only "No keyboard device detected"

① Make sure you plugged in the keyboard's own USB cable, not the wireless receiver (receivers cannot be configured);
② Close other programs that use the keyboard (old configuration software, other browser tabs);
③ Unplug and reconnect the USB cable, then try again;
④ Click "Can't find your device? List all vendor devices" below the button;
⑤ If you opened the tool in an in-app embedded window, copy the address into a standalone Chrome / Edge window.

Q2: "Bluetooth wireless model detected — please download the dedicated software" appears

This means the current device uses the Bluetooth protocol and that model is not yet supported on the web. Download the dedicated software as prompted. If your keyboard does support web configuration, first make sure it is connected with a USB cable and update to the latest firmware.

Q3: The model shows "Unknown" after connecting — what should I do?

A Select model manually dropdown appears in the device information area — pick the matching model. The available options then follow that model's capabilities.

Q4: Lighting / keys don't change after saving

① Click "Read Config" to read back from the keyboard and confirm it really was written;
② On some models, lighting requires selecting "Custom Color" and sending the color separately; switch to another mode and save once, then switch back;
③ On multi-layer devices, make sure you edited the current layer and that you clicked "Save to Keyboard".

Q5: Why don't I have a "Layer" switch or "Delay" settings?

Both capabilities are determined by the hardware / firmware. Single-layer models show no layer switch; models that don't support delays show no delay area. See the quick reference table in Chapter 8.

Q6: Will the configuration be lost? Does it still work on another computer?

The configuration is written to the keyboard's internal flash, so it survives power loss, switching computers, and reinstalling the OS. The web app's "configuration profiles" are stored separately in the browser — use Export / Import JSON to move them to another computer.

Q7: Can I use the web and desktop versions at the same time? Will their configurations overwrite each other?

You can install both, but do not connect the same keyboard from both at once — two programs competing for the device will fail to connect. Profile storage is independent; to migrate, use JSON export and import.

Q8: Can't connect on Linux

You need to grant udev permissions for hidraw. The tool provides commands you can copy directly, or download fix-keyboard-permission.desktop and double-click to run it; unplug and reconnect the keyboard afterwards.

Q9: How do I use the key test?

Click "🎯 Key Test" on the connection page or configuration page to open the test screen. Pressing a key on the keyboard highlights it in real time and shows the function currently assigned to it, along with the raw HID data — the fastest way to troubleshoot "the key doesn't work".

Q10: How many steps can a multi-key combo / macro have?

7–50 steps depending on model for the legacy protocol; for the new protocol and Bluetooth models it depends on macro capacity (the page shows the number of steps used). If you exceed it, saving fails with a prompt.
