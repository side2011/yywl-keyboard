# YYWL 键盘 · 运行环境自检工具

客户反馈“插上键盘没反应 / 提示无法识别的 USB 设备 / 网页打不开”时，
让他双击 `运行环境自检.bat`，把生成的 `yywl-环境自检-<时间>.txt` 发回来，
不用远程就能判断卡在哪一环。

## 文件

| 文件 | 说明 |
|---|---|
| `运行环境自检.bat` | 客户双击这个（GBK 编码，中文 Windows 控制台正常显示） |
| `yywl-env-check.ps1` | 实际检测逻辑（UTF-8 **带 BOM**，否则 Win7 的 PowerShell 5.1 会按 ANSI 解析中文导致语法错误） |

## 检测项

1. **系统版本/架构** —— Win7 不支持网页版（需要 Chrome/Edge 111+），会直接给出结论与替代方案
2. **浏览器版本** —— Chrome / Edge 是否存在、主版本是否 ≥ 111（WebHID 要求）
3. **USB 控制器** —— 是否只有 USB2.0；Win7 + USB3.0 未装驱动是“无法识别”的高频原因
4. **键盘是否被识别** —— 按 VID `1189/514C` + PID `8842/8840/8830-8833/8850` 匹配，显示设备名与错误码
5. **有问题的设备** —— `ConfigManagerErrorCode` 非 0，并把常见码翻译成人话
   （24/45/21 属于“未连接/未安装”，已过滤掉，不制造噪音）
6. **USB 选择性暂停** —— 开启时会导致偶发断连

## 常见错误码对照

| 码 | 含义 | 处理 |
|---|---|---|
| 28 | 未安装驱动 | 让 Windows 自动搜索驱动；或用厂商驱动 |
| 43 | 设备报告故障 | 换 USB2.0 口 / 换线 / 换电脑（多为供电或线材） |
| 10 / 31 | 无法启动 / 驱动加载失败 | 卸载设备后重新插拔 |
| 22 | 设备已禁用 | 设备管理器里启用 |

## 编码注意事项（踩过坑）

- `.ps1` 必须 **UTF-8 with BOM**，否则 Win7 的 PowerShell 5.1 把中文按 ANSI 读 → 满屏乱码 + 语法错误
- `.bat` 用 **GBK(936)** 编码，不要加 `chcp 65001`（Win7 控制台字体不全，反而更乱）
- PowerShell 里不要用 `$pid`（只读自动变量），本项目改成 `$pidStr`
